# Twoface Portfolio

Multi-page portfolio site (Code / Snap) with a Vite frontend and Express API backend.

## Folder structure

```
/client                 Frontend source (Vite root)
  index.html            Landing page — lever switch
  code.html             Developer portfolio
  snap.html             Photography portfolio
  css/                  Page stylesheets
  js/                   Page scripts
  vite.config.js        Multi-page Vite config (3 entry points)

/server                 Express backend
  index.js              App entry (dev + prod)
  start.js              Production launcher (sets NODE_ENV=production)
  routes/
    api.js              API router — mounted at /api
  config/
    env.js              dotenv loader + config export

/dist                   Production build output (generated by `npm run build`)
```

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Starts **Vite** (frontend, port 5173) and **Express** (API only, port 3001) concurrently |
| `npm run build` | Builds all 3 HTML pages + assets into `/dist` |
| `npm run start` | Serves `/dist` as static files **and** mounts `/api` on a single port (3001) |
| `npm run lint` | ESLint across the project |
| `npm run format` | Prettier write across the project |

### Development

```bash
cp .env.example .env   # optional — defaults work out of the box
npm install
npm run dev
```

- **Frontend:** http://localhost:5173 (Vite dev server with HMR)
- **API:** http://localhost:3001/api/health

Express does **not** serve the frontend in dev — only `/api` routes.

### Production

```bash
npm run build
npm run start
```

- **Site + API:** http://localhost:3001 (static `/dist` + `/api` on one process)

## Adding API routes

1. Open `server/routes/api.js`
2. Add handlers to the exported `router` (e.g. `router.post('/contact', …)`)
3. Routes are automatically prefixed with `/api` — a handler at `/health` is served at `/api/health`

For larger features, add new files under `server/routes/` and mount them in `server/index.js`.

## Environment variables

Copy `.env.example` to `.env`:

| Variable | Default | Description |
|---|---|---|
| `PORT` | `3001` | Express server port |
| `NODE_ENV` | `development` | Set to `production` automatically by `npm run start` |
| `VITE_DEV_PORT` | `5173` | Vite dev server port |
